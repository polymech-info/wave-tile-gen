Polymech / Wave Studio

Open-source tool for parametric wave panels

Polymech publishes Wave Studio for panels you can machine. Shape a heightfield in the browser, watch the surface, and download an STL. The settings stay on this device.

Open Wave Studio Wave Studio source on GitHub

Shape a panel

Pick a pattern — dunes, ripples, topographic, weave, flow field, spiral, or sculpt — then set the stock in millimetres. Frequency, phase, warp, and amplitude change the heightfield. The preview is the same mesh the STL uses.

Stock and height

X and Y are the panel face. Z is the block. Base thickness is the solid under the wave, and amplitude is how far the surface rises above that base. Both stay inside the stock height.

A file you can cut

Export STL downloads a solid of that mesh. Export JSON saves the sliders; import JSON loads them back. The STL is the part. Prove the toolpath on the machine.

Settings stay in this browser

The current sliders and any named presets you save are stored in this browser for this site. Nothing from the panel is uploaded to Polymech. Another browser starts again from the defaults.

Source

Wave Studio is MIT licensed in the wave tile generator repository on GitHub. It is part of the open-source tools Polymech publishes while building manufacturing software.
